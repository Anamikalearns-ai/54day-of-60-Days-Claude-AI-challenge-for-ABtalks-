Key Learnings 
Design tokens reuse karna speed deta hai — pehle se defined colors/fonts (amber, sage, Fraunces/Inter/Plex Mono) use karne se naya card bhi instantly "on-brand" laga, without reinventing anything.
CSS-only bar chart possible hai — koi JS/library ke bina bhi animated bars (transform: scaleY() + CSS variable --bar-height) se data visualize ho sakta hai. Halka aur fast.
File-linking ek chhota sa cheez bhi poora page break kar sakta hai — agar style.css/script.js same folder me na ho ya naam match na kare, toh poora styling gayab ho jaata hai (jaisa aaj hua). Isliye har baar teeno files ek hi folder me check karna zaroori hai.
Signature visual repeat karna brand consistency banata hai — hero ka "corridor" curve line reuse karke case study ke growth-arc me use kiya, taaki poora site ek hi visual language bole.
Static HTML/CSS milestones Android pe risk-free hote hain — jab tak fetch() ya API call nahi hai, file directly content:// se khol ke test kiya ja sakta hai, Claude preview ki zaroorat nahi padti.
